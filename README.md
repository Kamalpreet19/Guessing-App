Guessing App – Java Number Guessing Game
The Guessing App is a console-based Java game where the player tries to guess a randomly generated number within limited attempts. The game provides hints, validates input, logs invalid attempts, and saves 
game results to a file.

Features:
Random number generation
Limited attempts
Hint system
Input validation with custom exception
Result saving using file handling
Previous game history display
Restart game option
Final summary display


Concepts Used: 
Java OOP
Exception Handling
File Handling
Loop Control
Boolean Flags


How to Run:
Compile all Java files
Run GuessingApp.java

Output:
Game results are saved in game_results.txt
